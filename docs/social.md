## LinkedIn / longer

I spent the weekend building an agent that does the part of my job I'm worst at.

I run Beat ID — a live guess-the-song night, Kahoot but for music. The product works. The
bottleneck is that booking a students' union takes me about 90 minutes, there are 150+ of
them in the UK, and I'm also the one running the nights.

Greenroom researches a union, writes a pitch that opens with something specific and
current about them, sends it, handles the reply, and negotiates — inside a policy file I
control. If a counter-offer is within my envelope it answers. If it isn't, it drafts a
holding reply that agrees to nothing, escalates to me, and cites the exact line:
`fee.floor = 500`, not "this seems low".

The bit I'm proudest of: it earns autonomy. Every target starts where nothing sends
without my approval. Three clean approvals and it graduates. One edit and it drops back.

It's live on my real inbox right now.

Built with Google ADK, Gemini 3.5 Flash on Vertex AI, and Cloud Run.
